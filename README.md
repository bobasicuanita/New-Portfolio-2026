# Konstantinos Karasavvas — Software Engineering Portfolio

A modern, interactive frontend portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

This project showcases my frontend engineering approach.

---

## ✨ Features

- Responsive modern UI
- Smooth scroll navigation
- Dynamic active section tracking
- Dark / Light theme toggle
- Animated navigation with Framer Motion
- Interactive contact modal
- EmailJS contact form integration
- Custom SVG branding & favicon
- Mobile-first responsive design
- Downloadable resume interaction effects
- Animated micro-interactions & hover states
- Clean component-driven architecture

---

## 🛠 Tech Stack

- **Next.js 15**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **EmailJS**
- **React Icons**
